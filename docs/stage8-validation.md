**одноразовой синтетической** (в настоящую базу ничего стратегического не подставлялось).

(21 событие), ревизия 139.

## 2. Одноразовая синтетическая база (полный путь карты)

E2E `apps/desktop/e2e/map.spec.ts` (реальный Electron + реальный MCP-процесс, временная `LIVING_MAP_HOME`):

* главный экран: цель сезона, путь вверх, утро/вечер, проект/этап/действие/«готово, когда»/«почему сейчас»,
  таймер на этом же экране; Начать → Пауза → Продолжить → Готово → следующее действие, путь тот же;
  рутины не в порядке действий, не в рабочем времени, не в контексте ИИ;
* карта A: действие → проект → сезон → год → 3 года → десятилетие; честный прогресс «Этап 1 из 1 · 0 из 2
  действий»; на карте нет «%»; Исполнитель на карте — тот же;
* карта B: уточнение формулировки не меняет нижнее и не устаревит предложение ИИ; смена курса сначала
  показывает последствия, ничего не переписывает, устаревит старое предложение, ведёт к «Попросить ИИ
  перестроить» → предложение маршрута → применяется только после подтверждения владельца; «Всё пересобрано»;
  новый сезон — то же с историей;
* карта C: три проекта, четвёртый отказан по-человечески, пауза освобождает место, возобновление при
  полных местах отказано, «Завершить» с подтверждением → в истории;
* карта D: рутины сохраняются, переставляются, выключаются, переживают перезапуск;
* пустая карта: каждый слой можно начать прямо с карты.

Миграция с точной формы реальной БД v17 (с backup, backfill, триггерами, единственностью слоёв, гонкой двух
процессов, перезагрузкой) — `packages/persistence-sqlite/test/map.test.ts`.
