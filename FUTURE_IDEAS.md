# Живая карта — отложенные идеи

Идеи, которые появились по ходу работы, но не нужны для Definition of Done текущего этапа (CLAUDE.md §4). Не план и не обязательство.

## Из Этапа 3 (ИИ-мозг через MCP)

- **Per-action «почему сейчас» в OrderedActionPlan.** Стратегическая причина для каждого действия (ARCHITECTURE §28). Нужна, когда появится `Сейчас` (Этап 4).
- **Proposal на изменение сезона и «Чем ты не хочешь жертвовать ради целей?».** Сейчас у ИИ нет никакого пути менять их — только сказать пользователю словами.
- **Блокировки и удаление/объединение действий в маршрутном Proposal.** Сейчас маршрут умеет только добавлять и править (без удаления и без смены статусов).
- **Ручное редактирование плана пользователем в UI.** Сейчас порядок меняет только ИИ (через Proposal или безопасную перестановку).
- **Более точный признак устаревания.** Сейчас любое изменение планировочного контекста делает Proposal устаревшим; можно сузить до реально затронутых сущностей, если это начнёт мешать на практике.
